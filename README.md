# Text Based Battleships
A text-based version of Battleships I made for a university module. This is written in C++.

---

## Video

[![Preview of the ASCII animation project on YouTube](https://img.youtube.com/vi/V3-i_du0qlA/0.jpg)](https://youtu.be/V3-i_du0qlA).

---

## Features
- 2 player battleships game. Each player places their ships on their own grid, and then take turns firing missiles at coordinates in order to destroy all of the other player's ships.
- Handles incorrect inputs from the user, prompting them to enter a different response. Incorrect inputs include empty strings, strings instead of integers, coordinates not matching the correct size of a ship.
- Handles inputs with different cases.
- Detects if the inputted start point and end point of each ship is in a horizontal or vertical line.
- Keeps track of how many ships from each player has been destroyed.
- Sound effects indicating whether a fired missile successfully hit a ship or missed.

---

## Improvements
- A web version that is playable in browser.
- The game opens in separate windows for each player.
